## 备案放行之后

双击 `deployment/publish-workbench.command`，或执行：

```sh
python3 deployment/activate_public.py
```

只检测：加 `--check`。退回本机模式：加 `--rollback`。

备案放行前无法完成的只有这一版本的**公网来源放行验收、公开受信任证书签发和实际公网登录/预览验收**。相关配置与执行步骤已写好，不声称证书或公网已经可用。证书签发不等同于备案完成，脚本始终以实际网络可达性为准。

这份验收覆盖当前版本支持的公开 GitHub / 静态 / Dockerfile 部署链路；Nixpacks 方案、私有仓库授权、业务密钥、数据库及多服务项目仍需按项目验证与配置。平台备份不包含应用业务数据库卷。
