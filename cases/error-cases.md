# 验证问题记录

## 2026-10-18：sudo 清理环境变量导致 Compose 镜像变量丢失

- 事实：第一轮验证完成 Git 克隆和 Python 镜像构建，但通过 sudo 启动 Compose 时，调用方传入的 APP_IMAGE 被清理，Compose 因缺少镜像配置拒绝启动。
- 影响：测试环境未启动；线上展示页未受影响。
- 修复：改用显式 `docker compose --env-file` 传递非敏感镜像标签，避免依赖 sudo 环境变量继承。
- 后续：以修复后的完整验证结果为准。此记录是本项目事实，不是通用技能规则。

## 2026-10-18：仅内部网络的入口容器无法通过宿主端口访问

- 事实：第二轮容器均启动，但入口代理仅连接 internal 网络，宿主端口健康检查超时；修改为入口代理双网络后，静态页面及后端健康检查通过。
- 修复：入口代理连接 ingress 和 internal 两个网络；业务容器仅连接 internal，端口仍仅绑定宿主 loopback。
- 影响：仅本次测试环境；未修改现有展示页网络或端口。
